# testos — минимальная Java-«ОС» для iPod Touch 4G

Отдельный проект внутри репозитория, не трогает `swipeuplock`. Цель: заменить
SpringBoard на собственный полноэкранный «рабочий стол», логика которого
пишется на Java и исполняется нашей же мини-JVM.

## Архитектура (решение, принятое на старте)

Порт полноценной JVM (JamVM/CACAO + GNU Classpath) под armv7-apple-darwin —
это месяцы работы: нужно реализовать сотни нативных методов
(java.lang/io/util, потоки, GC под старый Darwin libc). Слишком тяжело для
хобби-проекта.

Вместо этого делаем свою предельно урезанную JVM, которая понимает ровно
тот набор байткода, который нужен нашим 5 программам (рабочий стол, 3
утилиты, 1 игра). Никакого java.lang.* — только несколько «нативных»
методов, которые мы сами придумываем и реализуем в C (рисование,
обработка тача, таймер).

Компоненты:

- `vm/` — сама мини-JVM на C: парсер `.class`-файлов + интерпретатор
  байткода. Портируемый код, без платформенных зависимостей. Разрабатывается
  и тестируется прямо на Linux (`javac` компилирует `.java` → `.class`,
  наш `vm` их исполняет), потом кросс-компилируется под iOS тем же Theos
  тулчейном, что и `swipeuplock`.
- `native-bridge/` — iOS-часть (Theos/Objective-C): полноэкранное UIKit
  окно вместо SpringBoard, которое даёт Java-стороне несколько «системных
  вызовов» — нарисовать прямоугольник/текст, получить тач, таймер кадра.
  Всё UI-рисование, шрифты, тач-хендлинг — от UIKit бесплатно, мы не пишем
  свой фреймбуфер-драйвер.
- `apps/` — сами программы на Java: `Desktop.java` (рабочий стол с
  иконками), 3 утилиты, 1 игра.

## Этапы (майлстоуны)

1. **M1 (сейчас)** — парсер class-файлов + интерпретатор базового
   байткода, тестируется на Linux консольным выводом (без графики).
   Доказываем, что подход работает.
2. **M2** — расширяем байткод под нужды реальных программ (объекты,
   массивы, вызовы методов друг друга).
3. **M3** — кросс-компиляция `vm/` под armv7-apple-darwin, прогон через
   SSH на устройстве (пока без UI, только консоль).
4. **M4** — `native-bridge`: полноэкранное UIKit-окно + мост
   рисование/тач в Java-нативные методы.
5. **M5** — пишем сами приложения (Desktop, утилиты, игра) на Java.
6. **M6** — LaunchDaemon, который останавливает SpringBoard и поднимает
   наше окно при загрузке (с возможностью отката).
